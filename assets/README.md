## 화면 사진 찍는 법

```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 을 열고 예시 질문(예: "사진 보고 글로 설명해주는 AI")
으로 검색한 뒤, **"이렇게 검색했습니다" 칸과 찾은 논문 목록이 함께 보이는 상태**를 찍어
`assets/screenshot.png` 로 저장하면 README 에 바로 나온다.

가로 1400픽셀 안팎이면 충분하다.
