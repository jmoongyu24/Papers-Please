# results/ - 보고서가 인용하는 확정 결과

여기에는 **검증을 거쳐 "확정"으로 판정한 실행 결과만** 둔다. 커밋해서 나중에 재현·검증할 수
있게 한다. 굴러가며 나오는 임시 결과는 `runs/` 에 두고, 그쪽은 버전 관리에서 제외돼 있다.

## 지금 들어 있는 것 (2026-08-14 확정)

평가셋 **v2 시험용 342문항** (`data/eval/test.jsonl`), 등급 정답지 `data/eval/grades_test.jsonl`.
검색 후보는 채널마다 100편, 재정렬은 교차 인코더 깊이 300.
로컬 의미 검색에는 **원본 질문**을 넣었다(서비스와 같은 조건, `--local-query raw`).

| 파일 | 구성 | Recall@10 | nDCG@10 |
|---|---|---|---|
| `test_passthrough.jsonl` | 변환기 없음 + 두 채널 | 0.553 | **0.458** |
| `test_dpo.jsonl` | 변환기(dpo) + 두 채널 = **지금 서비스** | **0.570** | 0.442 |
| `test_dpo_only_local_dense.jsonl` | 로컬 의미 검색 단독 | 0.553 | **0.484** |
| `test_dpo_only_arxiv.jsonl` | arXiv 단독 | 0.389 | 0.251 |
| `test_translate_rerankraw.jsonl` | **한국어를 영어로 옮겨 로컬 검색** | **0.608** | **0.512** |

**짝지은 부트스트랩 검정 (기준: 변환기 없음 / 로컬 단독)**

| 비교 | Recall@10 | nDCG@10 |
|---|---|---|
| 변환기 있음 vs 없음 | +0.018 (p=0.101, 판정 불가) | −0.016 (p=0.008, 유의미) |
| 두 채널 vs 로컬 단독 | +0.018 (p=0.101, 판정 불가) | −0.043 (p<0.001, 유의미) |
| **번역 vs 로컬 단독** | **+0.056 (p=0.001, 유의미)** | **+0.027 (p<0.001, 유의미)** |
| ↳ 한국어 문항만 | +0.111 (p=0.001) | +0.055 (p<0.001) |
| ↳ 영어 문항만 (대조군) | +0.000 | −0.000 |

해석은 [../docs/ISSUE.md](../docs/ISSUE.md) #37 참고.

**다시 집계하려면** (검색 0회):

```
$PY -m evaluation.report --run results/test_passthrough.jsonl results/test_dpo.jsonl \
    --queries data/eval/test.jsonl --grades data/eval/grades_test.jsonl
```

## 파일을 넣을 때 함께 적을 것

1. **어느 평가셋에서 잰 값인가** (`data/eval/dev.jsonl` / `test.jsonl`)
2. **어느 커밋인가** (실행 결과 파일의 `_meta` 줄에 자동으로 들어간다)
3. **기준선(passthrough) 값이 함께 있는가** - 없으면 "좋아졌다"를 말할 수 없다
