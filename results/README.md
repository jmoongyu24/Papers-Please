## 2026-08-16 확정 — 지금 서비스 구성

`test_multiquery_d100.jsonl` — 검색어 2개(번역 + 가상 초록)로 로컬 색인을 두 번 찾아 순위
합치기, 후보 100편, 교차 인코더 재정렬. **`app.py` 가 실제로 하는 것과 같은 구성임.**

| 구성 | Recall@10 | nDCG@10 |
|---|---|---|
| `test_multiquery_d100.jsonl` (지금 서비스) | **0.617** | **0.521** |
| `test_translate_rerankraw.jsonl` (옛 기준선) | 0.608 | 0.512 |
| 차이 | +0.009 (p=0.574, 판정 불가) | +0.009 (p=0.050, 판정 불가) |

**이득은 확정되지 않았음.** 개발용에서는 nDCG 가 p=0.040 으로 유의미했으나 시험용에서
경계에 걸림. 이 구성을 고른 근거는 성능이 아니라 ⓐ 두 지표 어느 쪽도 나빠지지 않음
ⓑ 응답 시간 21.1초 -> 15.1초 ⓒ 옛 구성이 코드상 고장나 있었음(ISSUE #39) 임.

난이도별: easy 0.930 · medium 0.658 · hard 0.263. **hard 층은 개선되지 않았음.**
